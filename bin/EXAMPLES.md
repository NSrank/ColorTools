# ColorTools 使用示例

本文档提供了 ColorTools 插件的详细使用示例，帮助你快速掌握 MineDown 格式的使用方法。

---

## 🎨 基础格式化示例

### 文本样式

#### 粗体文本
```
输入: **这是粗体文本**
效果: 显示为粗体的"这是粗体文本"
```

#### 斜体文本
```
输入: ##这是斜体文本##
效果: 显示为斜体的"这是斜体文本"
```

#### 下划线文本
```
输入: __这是下划线文本__
效果: 显示为带下划线的"这是下划线文本"
```

#### 删除线文本
```
输入: ~~这是删除线文本~~
效果: 显示为带删除线的"这是删除线文本"
```

#### 混淆文本
```
输入: ??这是混淆文本??
效果: 显示为混淆效果的"这是混淆文本"
```

### 组合样式
```
输入: **##粗体斜体文本##**
效果: 同时显示粗体和斜体效果

输入: __**粗体下划线文本**__
效果: 同时显示粗体和下划线效果
```

## 🌈 颜色格式示例

### 传统颜色代码
```
&0 黑色文本
&1 深蓝色文本
&2 深绿色文本
&3 深青色文本
&4 深红色文本
&5 紫色文本
&6 金色文本
&7 灰色文本
&8 深灰色文本
&9 蓝色文本
&a 绿色文本
&b 青色文本
&c 红色文本
&d 粉色文本
&e 黄色文本
&f 白色文本
```

### 十六进制颜色
```
输入: &#ff0000这是红色文本
效果: 显示为纯红色的文本

输入: &#00ff00这是绿色文本
效果: 显示为纯绿色的文本

输入: &#0000ff这是蓝色文本
效果: 显示为纯蓝色的文本

输入: &#ff6600这是橙色文本
效果: 显示为橙色的文本
```

### 渐变色
```
输入: &#ff0000-#0000ff&红蓝渐变文本
效果: 从红色渐变到蓝色的文本

输入: &#ffff00-#ff00ff&黄紫渐变文本
效果: 从黄色渐变到紫色的文本

输入: &#00ff00-#ff0000-#0000ff&三色渐变
效果: 绿色→红色→蓝色的渐变文本
```

### 彩虹色
```
输入: &rainbow&彩虹文本示例
效果: 显示为彩虹色的文本

输入: &rainbow&**粗体彩虹文本**
效果: 粗体的彩虹色文本
```

## 🔗 交互元素示例

### 点击执行命令
```
输入: [点击查看帮助](command:/help)
效果: 点击后执行 /help 命令

输入: [点击传送到出生点](command:/spawn)
效果: 点击后执行 /spawn 命令

输入: [点击获取物品](command:/give @s diamond 1)
效果: 点击后执行给予钻石命令
```

### 点击打开链接
```
输入: [访问官网](https://minecraft.net)
效果: 点击后在浏览器中打开 Minecraft 官网

输入: [查看插件页面](https://github.com/your-repo/ColorTools)
效果: 点击后打开插件的 GitHub 页面
```

### 悬停显示提示
```
输入: [悬停查看详情](https://example.com 这里是详细信息)
效果: 鼠标悬停时显示"这里是详细信息"

输入: [神秘物品](command:/give @s diamond 这是一颗珍贵的钻石)
效果: 悬停显示物品描述，点击获得物品
```

### 复杂交互
```
输入: [**&a点击领取奖励**](command:/give @s emerald 10 &7点击领取10个绿宝石奖励！)
效果: 绿色粗体文本，点击执行命令，悬停显示提示
```

## 🎮 游戏场景应用示例

### 聊天消息
```
玩家输入: 大家好！我找到了**&6传说级装备**！
显示效果: 大家好！我找到了传说级装备！（装备名称为金色粗体）

玩家输入: &#ff0000-#ffff00&危险！前方有怪物！
显示效果: 红黄渐变的警告文本
```

### 服务器公告
```
管理员输入: /broadcast **&a服务器维护通知**：服务器将在[**&c10分钟**](command:/time 明天上午10点开始维护)后重启
显示效果: 绿色粗体标题，红色粗体时间，点击查看具体时间
```

### 欢迎消息
```
配置文件中: 欢迎 **&b{player}** 加入服务器！[点击查看规则](command:/rules 服务器规则)
显示效果: 欢迎 玩家名 加入服务器！（玩家名为蓝色粗体，规则链接可点击）
```

### 死亡消息
```
原始消息: Player was slain by Zombie
处理后: **&c{player}** &7被 **&4僵尸** &7杀死了
显示效果: 红色粗体玩家名，灰色文本，深红色粗体怪物名
```

### 成就消息
```
输入: &a{player} &7获得了成就 [**&e{achievement}**](achievement:{id} {description})
显示效果: 绿色玩家名，黄色粗体成就名，悬停显示成就描述
```

## 🛠️ 实用技巧

### 1. 颜色搭配建议
```
# 信息类消息
&7[&b信息&7] &f消息内容

# 警告类消息  
&7[&e警告&7] &e消息内容

# 错误类消息
&7[&c错误&7] &c消息内容

# 成功类消息
&7[&a成功&7] &a消息内容
```

### 2. 层次化信息
```
**&6=== 服务器公告 ===**
&7时间：&e2024年1月1日
&7内容：&f服务器将进行例行维护
&7详情：[点击查看](https://example.com 维护详情页面)
**&6==================**
```

### 3. 交互式菜单
```
**&6=== 传送菜单 ===**
[&a出生点](command:/spawn 传送到出生点)
[&b主城](command:/warp city 传送到主城)
[&c竞技场](command:/warp arena 传送到竞技场)
[&e商店](command:/warp shop 传送到商店)
**&6===============**
```

### 4. 状态显示
```
&7玩家状态：
&7❤ 生命值：&c{health}/20
&7🛡 护甲值：&9{armor}/20
&7💰 金币：&e{money}
&7📍 位置：&f{world} ({x}, {y}, {z})
```

## 📝 注意事项

### 1. 性能考虑
- 避免过度复杂的格式化
- 合理使用缓存功能
- 大量消息时考虑异步处理

### 2. 兼容性
- 测试与其他插件的兼容性
- 注意事件处理优先级
- 检查客户端支持情况

### 3. 用户体验
- 保持格式一致性
- 避免过度使用特效
- 确保重要信息清晰可见

### 4. 调试技巧
```bash
# 启用调试模式查看处理过程
/colortools debug on

# 测试特定格式
/colortools test **&a测试文本**

# 查看处理统计
/colortools status
```
