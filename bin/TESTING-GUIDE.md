# ColorTools 测试指南

本指南将帮助你测试 ColorTools 插件的修复，特别是死亡消息和颜色代码处理功能。

---

## 🔧 修复内容

### 1. **API兼容性修复**
- 修复了 `PlayerDeathEvent.deathMessage()` 方法的调用问题
- 修复了所有事件监听器中的 Component 序列化问题
- 使用 `LegacyComponentSerializer` 替代 `PlainTextComponentSerializer` 以正确处理颜色代码

### 2. **十六进制颜色处理优化**
- 改进了 `&#rrggbb` 格式的颜色代码处理
- 支持 `&#rrggbb&` 格式（带结束符）
- 支持渐变色格式 `&#rrggbb-#rrggbb&`
- 转换为 MineDown 兼容的格式

### 3. **调试功能增强**
- 添加了详细的调试日志
- 显示原始消息和处理后的消息
- 更好的错误追踪和诊断

## 🐛 故障排除

### 如果颜色仍然不显示

1. **检查客户端支持**
   - 确保使用支持十六进制颜色的客户端
   - Minecraft 1.16+ 原版客户端支持十六进制颜色

2. **检查服务器版本**
   - 确保使用 Paper 1.20.1+
   - 检查 Adventure API 版本

3. **检查插件配置**
   ```bash
   /colortools status
   # 确保 MineDown 处理已启用
   ```

### 如果仍有错误

1. **查看完整错误日志**
   ```bash
   tail -f logs/latest.log
   ```

2. **启用详细调试**
   ```bash
   /colortools debug on
   # 编辑 config.yml 设置 verbose-logging: true
   /colortools reload
   ```

3. **检查依赖冲突**
   ```bash
   /plugins
   # 查看是否有其他聊天插件冲突
   ```
