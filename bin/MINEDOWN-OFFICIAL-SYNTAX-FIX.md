# 基于MineDown官方语法的颜色修复

本文档介绍了基于MineDown官方语法文档的颜色代码处理修复。

---

## 🎯 **关键发现**

### **MineDown官方语法**
从MineDown官方文档中，我们发现了正确的颜色代码格式：

| 描述 | 语法 | 示例 |
|------|------|------|
| RGB Hex Color | `&#ff00ff&Text` | Full hexadecimal format |
| RGB Hex Color | `&#f0f&Text` | Short format (equivalent to long one) |

**关键点**：MineDown的颜色代码格式是 `&#rrggbb&Text`，需要在颜色代码后有结束的 `&` 符号！

### **实际JSON结构分析**
```json
{
  "extra": [
    {"text": "&#55B1C2&["},      // ✅ 有结束&
    {"text": "&#8B0000&莫斯科"},  // ❌ 没有结束& - 这是问题所在！
    {"text": "&#55B1C2&] "}      // ✅ 有结束&
  ]
}
```

**问题根源**：
- `{"text": "&#8B0000&莫斯科"}` 缺少结束的 `&` 符号
- 应该是 `{"text": "&#8B0000&莫斯科&r"}` 才能正确截断颜色
- 我们之前的正则表达式没有处理这种不完整格式

---

## 🔧 **修复方案**

### **基于MineDown官方语法的正则表达式**

#### **修复前（错误的假设）**
```java
// 假设所有颜色代码都有完整格式
result = result.replaceAll("(\"text\":\"[^\"]*&#[0-9a-fA-F]{6}&[^\"]*?)\"", "$1&r\"");
```

#### **修复后（正确的处理）**
```java
// 基于MineDown官方文档的颜色代码处理
// MineDown格式：&#rrggbb&Text - 需要在颜色代码后添加&r来截断颜色

// 策略1：处理已经有结束&的完整格式 - 在text字段末尾添加&r
result = result.replaceAll("(\"text\":\"&#[0-9a-fA-F]{6}&[^\"]*?)\"", "$1&r\"");
result = result.replaceAll("(\"text\":\"&#[0-9a-fA-F]{3}&[^\"]*?)\"", "$1&r\"");

// 策略2：处理没有结束&的不完整格式 - 先添加&，再添加&r
result = result.replaceAll("(\"text\":\"&#[0-9a-fA-F]{6})([^&\"]+?)\"", "$1&$2&r\"");
result = result.replaceAll("(\"text\":\"&#[0-9a-fA-F]{3})([^&\"]+?)\"", "$1&$2&r\"");

// 策略3：处理只有颜色代码没有文本的情况
result = result.replaceAll("(\"text\":\"&#[0-9a-fA-F]{6})\"", "$1&r\"");
result = result.replaceAll("(\"text\":\"&#[0-9a-fA-F]{3})\"", "$1&r\"");
```

### **正则表达式匹配详解**

#### **策略1：完整格式处理**
```java
// 匹配: "text":"&#55B1C2&["
// 替换为: "text":"&#55B1C2&[&r"
"(\"text\":\"&#[0-9a-fA-F]{6}&[^\"]*?)\"" -> "$1&r\""
```

#### **策略2：不完整格式处理**
```java
// 匹配: "text":"&#8B0000莫斯科"
// 替换为: "text":"&#8B0000&莫斯科&r"
"(\"text\":\"&#[0-9a-fA-F]{6})([^&\"]+?)\"" -> "$1&$2&r\""
```

#### **策略3：只有颜色代码的情况**
```java
// 匹配: "text":"&#55B1C2"
// 替换为: "text":"&#55B1C2&r"
"(\"text\":\"&#[0-9a-fA-F]{6})\"" -> "$1&r\""
```
